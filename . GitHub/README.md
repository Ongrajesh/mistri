# Mistri – Android app

Opens the Mistri prototype (app/src/main/assets/index.html) inside a WebView.

## Build an APK
1. Install Android Studio and open this folder. Let Gradle sync (needs internet the first time).
2. Plug in an Android phone with USB debugging on (or start an emulator) and press Run.
3. For a file you can share: Build > Build Bundle(s) / APK(s) > Build APK(s).
4. For Play Store: Build > Generate Signed Bundle / APK > Android App Bundle.

To change the app, edit app/src/main/assets/index.html.
